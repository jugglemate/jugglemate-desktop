## 2. 每个任务的详细拆解

### 2.1 P1 — SLA 工单卡片 + 倒计时

**目标**：在工单详情卡顶部显示 SLA 倒计时 + 状态色 + 暂停按钮。

**交付物**：

1. `src/components/sla/SlaCard.vue` —— 详情卡顶部 SLA 区块
2. `src/components/sla/SlaChip.vue` —— 列表行轻量徽标
3. `src/services/sla.js` —— fetchSla / pauseSla / resumeSla / fetchSlaEvents
4. `src/stores/sla.js` —— Pinia store，按 ticket_id 缓存
5. `AgentPanel.vue` 集成 `<SlaCard>`
6. `TicketManagementView.vue` 列表行加 `<SlaChip>`

**关键行为**：

- 进入工单 → 自动 `fetchSla(ticketId)` → 渲染倒计时
- 倒计时每秒 tick（不调接口，纯前端计算 based on `first_response_remaining_seconds`）
- 状态色：`on_track` 绿 / `warning` 黄 / `breached` 红 / `paused` 灰
- 暂停按钮 → 弹确认框（reason 输入）→ `POST pause` → 刷新本地
- 列表行 chip：紧凑显示 `FRT 00:12` / `RES 01:45` / `⚠ 03m`

**DoD**：

- [ ] SlaCard / SlaChip 单元测试
- [ ] mock 数据可跑通 on_track / warning / breached / paused 四种状态
- [ ] 暂停 / 恢复可在 UI 走通
- [ ] 不影响现有 chat 消息流

### 2.2 P2 — CSAT 工单卡片 + 触发

**目标**：工单详情显示 CSAT 状态卡；工单关闭时自动发问卷（前端只负责展示触发结果）。

**交付物**：

1. `src/components/csat/CsatCard.vue` —— 详情卡
2. `src/components/csat/CsatBadge.vue` —— 列表行徽标
3. `src/components/csat/CsatModal.vue` —— 客户侧评分弹窗（如果前端需要）
4. `src/services/csat.js` —— fetchCsat / sendCsat / submitCsat
5. `src/stores/csat.js` —— Pinia store
6. `AgentPanel.vue` 集成 `<CsatCard>`
7. 监听工单状态变更（`status: 1 → 2`）→ 触发拉取新 CSAT 状态

**关键行为**：

- 工单关闭后显示 CSAT 状态：未发 / 已发 / 已收 / 已过期

- 手动重发按钮（主管可见）
- 客户侧评分提交成功后 UI 自动更新（IM SDK 推送 / 轮询）

**DoD**：

- [ ] 6 种状态（not_sent / pending / sent / submitted / expired / hidden）都有 UI
- [ ] 评分提交后状态切换正确
- [ ] 不会重复发问卷

### 2.3 P3 — 翻译：MessageTranslation 组件 + 切换

**目标**：每条消息支持 原文 / 译文 / 并列 三种视图；顶栏可全局切换。

**交付物**：

1. `src/components/translation/MessageTranslation.vue` —— 消息下方语言条
2. `src/components/translation/TranslationToggle.vue` —— 顶栏切换
3. `src/services/translation.js` —— translateMessage / fetchTranslations / updateMode
4. `src/stores/translation.js` —— Pinia store（按 message_id 缓存 + 全局 mode）
5. `message/MessageItem.vue` 集成 `<MessageTranslation>` slot
6. `Conversations.vue` / `ChatMain.vue` 顶栏加 `<TranslationToggle>`
7. `AgentPanel.vue` 加 "Translation Settings" 卡片

**关键行为**：

- 收到非母语消息 → 自动 `translateMessage(msgId, {targetLang})` → 写入 store
- 消息下方显示：`🌐 zh-CN → en-US | Confidence: High | View original`
- 顶栏切换影响所有未读消息的渲染模式
- 切到 "split view" 时原文 / 译文并列
- 敏感内容（pii / sensitive）自动脱敏显示，标注 "Sensitive content hidden"

**DoD**：

- [ ] 三种视图可正常切换
- [ ] 翻译失败 / 加载中 / 低置信度都有 UI
- [ ] 原文永远保留，不会被覆盖
- [ ] 敏感内容能脱敏

## 4. 风险与注意事项

1. **i18n 越早越好**：F1 越晚接，全文替换 `$t()` 成本越高
3. **时间字段统一 unix ms**：避免字符串和数字混用
4. **敏感内容合规**：P5 不要等海外上线前再做
5. **翻译 provider 可插拔**：不要硬绑 Google / DeepL
6. **倒计时性能**：长会话 SLA 卡片每 1s tick，要用 `requestAnimationFrame` 而不是 setInterval
