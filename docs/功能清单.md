# JuggleMate 坐席工作台 功能清单

> 对应包：`jugglemate-agent`（内部也叫 `jugglemate-web`）
> 形态：Electron 桌面客户端（Vue3 + Vite + Electron）
> 本文基于 `src/` 实际实现归纳，区分「已实现 / 计划中 / 明确不做」。产品视角说明见 `docs/PRODUCT.md`。

---

## 1. 项目定位

面向客服/运营的**多平台私信 + 多 AI Agent 协作**工作台：把 Web / Telegram / JuggleIM 等渠道私信收进统一收件箱，每个会话旁有 AI Agent 的回复建议与接管能力，复杂任务可拉一组 Agent 进「群组」协同。坐席端，对应 C 端为 `jugglemate-customer-chat`。

---

## 2. 已实现功能（✅）

### 2.1 账号

| 功能 | 说明 |
|---|---|
| 登录 / 注册 / 退出 | 账号 6–20 位字母数字，密码 ≥6 位；token 持久化 + 自动重连 IM |
| 错误码映射 | 账号不存在 / 密码错 / 账号已存在 / 参数错 |
| 注册流程 | 成功后账号进「已使用列表」缓存，1.5s 后跳登录（不自动登录） |

### 2.2 会话列表（Conversations）

| 功能 | 说明 |
|---|---|
| 筛选 | 全部 / 未读 / 接管中 |
| 置顶条 | IM 返回 `isTop` 时在主列表上方出现头像条 |
| 条目展示 | 头像（用户名 hash 着色 + 平台标）/ 会话名 / 预览 / 时间 / 未读红点（99+ 截断，免打扰变点） |
| 状态 | 本地占位 + IM 实时；IM 未连时显示本地占位 |
| 右键菜单 | 标记未读、删除会话（置顶/免打扰/清空消息菜单入口已留位，本期未接） |
| typing 提示 | 收到 `snl:typing` 显示「对方正在输入」（5s 自动消失） |
| 事件订阅 | STATE_CHANGED / CONVERSATION_CHANGED / ADDED / REMOVED / MESSAGE_RECEIVED / CONVERSATION_TOP |

### 2.3 聊天主区（ChatMain）

| 功能 | 说明 |
|---|---|
| 头部 | 头像 + 会话名 + 平台标签（抖音/小红书/Telegram）+ 在线状态 |
| 接管横幅 | 单聊「接管/收回」切换；接管中脉动 banner |
| 历史消息 | `getMessages` 分页、上滑加载、保留视觉位置、时间分隔条 |
| 消息操作 | 复制、引用、表情回应、撤回、删除、转发（合并转发） |
| 消息类型 | text / image / file / video / voice / contact card / merge / reaction / recall / timeline / unknown（11+ 类） |
| 附件发送 | 图片/视频/文件带进度条与本地预览；失败可读提示（识别 `1302 UPLOAD_PLUGIN_ERROR`） |
| Agent 建议 | 取前 3 条建议扁平展示，点击填入；Ctrl+1/2/3 快捷键 |
| 输入区 | 附件 + textarea + 发送；Enter 发送 / Shift+Enter 换行；上传后自动 focus |
| 引用 banner | `ReplyQuote` 显示被引用消息预览，可取消 |
| 图片预览 | `ImagePreviewer` 全屏灯箱 |
| 表情选择器 | `EmojiPicker` 乐观更新 + 失败回滚 |
| 转发对话框 | `TransferDialog` 选目标会话发 merge-forward |
| typing 上报 | 单聊（非群）才发；3s 节流；blur 主动发 END |

### 2.4 Agent 体系

| 功能 | 说明 |
|---|---|
| Agent 列表 | emoji + 名称 + 角色 + 每 Agent 3 条建议 |
| 创建 Agent | 侧滑表单：名称/角色/回复风格/知识库(UI)/适用平台/接管权限/温度/最大长度 |
| Agent 群组 | 群组内多 Agent 协作聊天室视图（当前 demo 数据，不接 IM） |
| 接管 | 单聊模式「接管/收回」横幅；接管时建议变灰 |

> ⚠️ 本期 Agent 体系**纯前端 demo**：建议是写死文本、创建 Agent 不落后端、群组不接 IM、不调任何 LLM。真实 Agent 协同由 `jugglemate-server` 的 Agent 平台 + `jugglechat-electron` 承载。

### 2.5 布局与通用

| 功能 | 说明 |
|---|---|
| 三栏/双栏切换 | TitleBar 切换；专注模式自动收起 Agent 面板 |
| 通用组件 | Avatar / Button / Input / Modal / Slideover / Toggle / Toast / EmojiPicker |

## 4. 明确不做（当前阶段）

- 表情贴纸库
- 阅后即焚
- i18n / 多语言

- 把 `localhost:8050` 改成可配置
- Agent 真正接 LLM

---

## 5. 已知限制

- **API 地址硬编码**：换环境必须改 `src/config.js`（当前 `localhost:8050`）。
- **冷启动不恢复上次会话**：刷新后回空状态。
- **会话搜索框**仅样式，搜不出东西。
- **附件上传依赖后端存储插件**：未配置得 `1302` 错误（已做可读化）。
- **Agent 体系完全 demo 化**：所有「AI」行为为预设字符串。
- **群组视图不走 IM**：纯前端数据。
