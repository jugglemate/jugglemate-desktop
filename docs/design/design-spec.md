# 产品设计规格书 - JuggleMate（智联桌面聊天工具）

> 版本：v1.0 | 日期：2026-06-05

---

## 1. 产品定位

JuggleMate 是一款面向个人用户和专业运营者的桌面端 AI 聊天中枢。它聚合多平台私信消息，通过可配置的 AI Agent 提供实时回复建议、会话接管，以及多 Agent 群组协商能力。

**核心价值主张**：一个窗口，管理所有平台的对话；一个面板，调度所有 AI 助手。

---

## 2. 用户画像与核心场景

| 用户类型 | 核心场景 | 痛点 |
|---------|---------|------|
| 内容创作者 | 同时运营抖音/小红书/TG，每天处理上百条粉丝私信和内容合作邀约 | 多 App 来回切换，回复效率低，错过商机 |
| 电商/客服运营 | 管理抖音小店、小红书店铺等多渠道客户咨询 | 重复问题大量时间消耗，标准化回复难以执行 |
| 高级个人用户 | 多平台社交，希望用 AI 提升沟通效率 | 想用 AI 辅助但缺乏易用工具 |

### 3.1 桌面客户端层

| 模块 | 职责 |
|------|------|
| 会话列表面板 | 按平台/状态聚合展示所有会话，支持筛选、搜索、置顶 |
| 聊天主面板 | 消息气泡渲染、实时 Agent 建议预览、接管状态指示 |
| Agent 面板 | Agent 创建/编辑/启停、接管规则配置、知识库管理 |
| 多 Agent 群组 | 聊天室 UI、Agent 发言编排、用户插话/引导 |
| 布局切换 | 三栏 ↔ 双栏切换，专注模式适配 |

### 3.2 云端服务层

| 服务 | 职责 |
|------|------|
| 平台适配器集群 | 统一消息格式(Schema)，官方 API + 模拟登录混合接入 |
| LLM 推理服务 | Agent 建议生成、接管回复、多 Agent 协商编排 |
| 数据 & 知识库 | 用户身份/Agent 配置持久化、Agent 记忆、RAG 文档索引 |

### 3.3 数据流

```
[平台新消息] → 适配器轮询 → 消息标准化 → WebSocket 推送到客户端
用户选择建议 → 客户端 HTTP → 适配器写回对应平台
用户开启接管 → 客户端 HTTP → LLM推理(带Agent上下文) → 适配器写回
多Agent群组  → 客户端 HTTP → LLM编排(多Agent多轮) → 流式推回客户端
```

## 4. 功能模块详细设计

### 4.1 平台账号接入

**流程：** 设置 → 添加平台 → 选择平台 → 授权/登录 → 绑定成功

**混合接入策略：**

| 平台 | 接入方式 | 说明 |
|------|---------|------|
| Telegram | Bot API / User API | 官方接口，稳定可靠 |
| 抖音 | 模拟登录 Web 端 | 拉取私信列表，免责提示 |
| 小红书 | 模拟登录 Web 端 | 拉取私信，免责提示 |

**消息统一 Schema：**
```
message UnifiedMessage {
  id: string;
  platform: "douyin" | "xiaohongshu" | "telegram";
  conversationId: string;
  sender: { id, name, avatar };
  content: { text?, images?, voice? };
  timestamp: number;
  isRead: boolean;
}
```

**状态指示：**
- 绿色圆点：平台在线，消息实时同步
- 黄色圆点：同步延迟（模拟登录平台偶发断开）
- 红色圆点：账号掉线，需重新授权

### 4.2 Agent 创建与配置

**结构化配置表单：**

| 配置项 | 类型 | 说明 |
|--------|------|------|
| Agent 名称 | 文本 | 如"客服助手"、"商务谈判官" |
| 角色描述 | 多行文本 | 一句话定义 Agent 身份和职责 |
| 回复风格 | 下拉选择 | 亲切活泼 / 专业正式 / 简洁直接 / 自定义 Prompt |
| 知识库 | 文件/链接 | 上传产品手册、FAQ、价目表等作为 RAG 素材 |
| 适用平台 | 多选 | 该 Agent 用于哪些平台的会话 |
| 接管权限 | 开关 | 是否允许该 Agent 接管会话 |
| 接管触发词 | 标签 | 如"价格"、"优惠"、"退换"等关键词触发自动接管 |
| 温度参数 | 滑块 | 控制回复的创造性 (0~1) |
| 最大回复长度 | 数字 | 限制单次回复字数 |

**Agent 列表管理：**
- 列表展示所有已创建的 Agent，含名称、角色标签、状态（启用/停用）
- 支持编辑、复制、删除、导出/导入 Agent 配置
- 主界面上 Agent 面板默认展示当前会话可用的 Agent 列表

### 4.3 Agent 实时回复建议

**交互流：**
1. 用户在聊天面板查看某会话
2. 对方发来新消息
3. Agent 面板区域实时出现 1~3 条候选回复（流式生成）
4. 用户可点击候选回复直接发送，或忽略自行输入

**建议面板 UI：**
- 每条候选回复前标注生成它的 Agent 名称和头像
- 候选回复以卡片形式呈现，点击即填入输入框并发送
- 支持快捷键：Ctrl+1/2/3 快速选取第 1/2/3 条建议
- 当多个 Agent 同时启用时，展示各 Agent 的 Top 建议

**生成策略：**
- 云端 LLM 接收本轮对话上下文 + Agent 角色设定 + 知识库 → 流式返回候选
- 客户端收到流式结果后渐进渲染，给用户"AI 正在思考"的体感
- 用户可对建议做「赞」「踩」反馈，用于优化 Agent

### 4.4 Agent 接管会话

**手动接管模式：**
1. 在聊天面板上方点击「交给 [Agent名]」按钮
2. 确认后，Agent 进入接管状态（面板出现明显视觉变化：边框变蓝 + "AI接管中"标识）
3. 此后对方消息到来时，Agent 自动生成回复并发送，无需用户确认
4. 对话流中 Agent 自动发送的消息带有特殊标识（蓝色边框 + "[Agent名] 自动回复"标签）
5. 用户可随时点击「收回控制」退出接管模式
6. 接管期间的对话记录完整保留，用户可事后审视

**条件自动接管：**
1. 在 Agent 配置中设置触发规则
2. 支持的触发条件：关键词匹配、时间段（如非工作时间）、发件人标签
3. 满足条件时自动进入接管，完成后可选择保持接管或自动退回手动模式
4. 自动接管发生时，系统在通知栏提示用户

**接管状态可视化：**
- 接管中：聊天头部显示醒目的蓝色接管横幅
- 待收回：Agent 最近一条自动回复旁有「撤回」按钮
- 接管日志：Agent 面板可查看接管历史和统计

### 4.5 多 Agent 群组协商

**创建群组：**
1. 点击「创建 Agent 群组」
2. 从已有 Agent 列表中选择 2~5 个 Agent 加入
3. 命名群组并保存

**聊天室协作模式：**
- 用户在群组输入框描述任务（如"帮我策划下个月双11的营销方案"）
- 各 Agent 依次发言，像真人会议一样讨论
- 用户可随时插话引导方向，如"聚焦在小红书渠道"、"预算控制在2万以内"
- 群组对话消息以各 Agent 的头像+名称标识

**编排策略（云端）：**
1. 用户抛出任务 → 云端编排器解析
2. 编排器将任务分发给各 Agent（带各自角色设定 + 任务上下文）
3. 各 Agent 生成初始发言 → 展示在聊天室
4. 编排器将其他 Agent 的发言作为上下文传递给每个 Agent
5. 多轮迭代（默认 3~5 轮），直到达成共识或用户叫停
6. 编排器最终生成总结，展示在聊天室底部

**群组管理：**
- 支持增删 Agent、修改群组名、归档群组
- 群组历史可导出为对话记录
- 支持保存为模板（如"营销策划组"、"技术方案评审组"）

## 6. 交互流程

### 6.1 核心操作流

```
启动 App → 查看所有会话 → 选中会话 → 收到消息 → Agent 提供建议
                                                      ↓
                                            ┌─ 采纳建议发送
                                            ├─ 自行输入回复
                                            └─ 开启接管（手动/规则）
                                                      ↓
                                               Agent 自动回复
                                                      ↓
                                               可随时收回控制
```

### 6.2 多 Agent 群组流

```
创建群组 → 选择 Agent 成员 → 输入任务 → Agent 开始协商
                                              ↓
                                    用户在聊天室观察讨论
                                              ↓
                                    ┌─ 插话引导方向
                                    ├─ 叫停并导出总结
                                    └─ 让 Agent 继续深入
```

## 7. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 消息同步延迟 < 2s，Agent 建议首字生成 < 1.5s |
| 安全 | 平台凭据加密存储，传输层 TLS 1.3，知识库文件端到端加密 |
| 合规 | 模拟登录平台需用户明确同意风险，提供免责声明 |
| 离线 | 历史消息本地缓存，Agent 配置离线可查看和编辑 |
| 扩展 | 平台适配器插件化，新增平台只需实现适配器接口 |
